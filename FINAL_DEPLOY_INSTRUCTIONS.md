## Deployment via GitHub + Netlify
1. Extract the ZIP and upload **its contents**, not the ZIP file, to the root of the existing GitHub repository.
2. Commit and push to `main` (or the branch configured in Netlify).
3. In Netlify, keep the site's publish directory as `public` and retain the existing environment variables; then verify the new deployment.
4. Test desktop and mobile views, open country Explore buttons, submit a test registration and check the WhatsApp group invitation and conversion event.
5. If your old event date still appears, clear the browser cache and check that the most recent Netlify deployment completed.

This package updates local source files. Your live Netlify site is **not** changed until you deploy them.
